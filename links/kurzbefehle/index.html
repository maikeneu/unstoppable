KURZBEFEHL 01

Lost Phone

Dein Handy ist weg? Eine vertraute Person schickt dir dein Codewort per Nachricht. Dann startet der Kurzbefehl auf deinem iPhone von allein.

KURZBEFEHL HOLEN
SO AKTIVIERST DU IHN
  1. Öffne die App Kurzbefehle und tippe auf Automation.
  2. Tippe auf Neue Automation und wähle Nachricht.
  3. Wähle eine vertraute Person als Absender.
  4. Lege ein Codewort fest.
  5. Verknüpfe die Automation mit dem Kurzbefehl Lost Phone.
